# signalboard

Real-time status board built to demonstrate production patterns:

- WebSocket fan-out with reconnect/backoff
- Role-based access control
- Hash-chained, tamper-evident audit log
- k6 load test in CI with published p95 latency

**Status: in development.** v1 targeted for Fall 2026. This repo exists so progress happens in the open — expect scaffolding, then working software.
